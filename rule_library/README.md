# Behavior Rule Architecture artifacts

This directory contains the reference artifacts associated with **Behavior
Rule Architecture (BRA)**. BRA is defined by the paper as a structured
framework for defining and managing AI execution behavior through normative
rules.

## Navigation

1. Begin with [`schema/README.md`](schema/README.md) for the representation
   layer and its NNL, RNL, and Rule materials.
2. Use [`rules/INDEX.md`](rules/INDEX.md) to browse individual CODE, SPEC, and
   language rules.
3. Use [`ruleset/INDEX.md`](ruleset/INDEX.md) for composed rulesets, then review
   the [known inherited inconsistencies](../provenance/VALIDATION.md#ruleset-reference-findings)
   before automated consumption.

The files are preserved from legacy source commit
`c36fb8df4221195b4c4a9801e8911a0af2378b83`, with only the top-level path moved
from `aisdgr/` to `rule_library/`. No terminology or rule semantics were
silently rewritten during that move.

Paper: [Behavior Rule Architecture](https://doi.org/10.5281/zenodo.19174636).
