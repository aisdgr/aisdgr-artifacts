The archive contains 189 files. It is a snapshot of the files retained by the
legacy repository, **not the complete Git revision history** and not a claim of
complete conceptual coverage. Branch-only experiments, working notes, chat
exports, superseded validation outputs, and content absent from the selected
source snapshot are not represented here. The reconstructed Git commits before
the public-layout commit provide additional selected checkpoints, but they also
do not reproduce the legacy repository's full commit graph.

When citing an archived artifact, include this repository's commit identifier,
the full path below `archive/history/`, and the legacy source commit above. File
checksums are available in [`provenance/SHA256SUMS`](../provenance/SHA256SUMS).
